# 📊 Pandas Analytics Journey

**Learning in the Open**: Documenting my learning process through core pandas, data manipulation, and structural mechanics using industry-standard resources.

## 🎯 Learning Goals

- Master pandas DataFrames, Series, and indexing mechanics
- Develop proficiency in data manipulation and transformation
- Build intuition around alignment, reshaping, and groupby operations
- Apply concepts to real-world datasets (Kaggle exercises)
- Create reusable patterns and solutions

## 📚 Primary Resources

1. **Python for Data Analysis, 3rd Edition** (Chapters 5–12)
   - Deep dive into structural mechanics
   - Comprehensive coverage of DataFrames and alignment
   - Skip chapters 1-4 (Python basics)

2. **Official Pandas "10 Minutes to pandas" Guide**
   - Syntax reference cheatsheet
   - Quick lookup for object creation and data selection
   - Keep open during coding sessions

3. **Kaggle's Micro-Course: Pandas**
   - Interactive 4-hour browser-based course
   - Real datasets and bite-sized problems
   - Practical application of concepts

## 📖 Notebook Structure

Each Marimo notebook follows this pattern:
- **Concept Overview** - What we're learning and why it matters
- **Theory & Mechanics** - How it works under the hood
- **Code Examples** - Progressive complexity from basic to advanced
- **Practice Exercises** - Hands-on problems to solidify learning
- **Common Pitfalls** - Gotchas and "Aha!" moments
- **Resource Reference** - Which guide covered this best
