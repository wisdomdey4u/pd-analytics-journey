# PD Analytics Journey

My learning journey through core pandas, data manipulation, and structural mechanics using Wes McKinney's Python for Data Analysis — documented in the open.

This repository is my public notebook for learning pandas with intention, reflection, and practical experimentation. The goal is not just to complete exercises, but to understand the patterns, trade-offs, and mental models behind the library.

## Why this repo exists

I am learning pandas in public so that:

- concepts become clearer through teaching and writing
- progress is visible and accountable
- code examples and notes can help others on the same path
- learning becomes a reusable body of work, not just ephemeral memory

## Fast-track resources

1. Python for Data Analysis, 3rd Edition (Chapters 5–12)
   - Primary deep-dive reference for pandas internals and data structures
   - Focus: DataFrames, indexing, alignment, reshaping, missing values, grouping

2. Official Pandas: 10 Minutes to pandas
   - Quick-reference syntax for creating objects, selecting data, and handling missing data

3. Kaggle's Pandas Micro-Course
   - Interactive exercises and real datasets for applied learning

## Learning philosophy

This repo follows a simple pattern:

- Read the concept
- Try the example
- Write my own notebook
- Reflect on what clicked
- Document the confusion and clarity
- Build a small challenge or experiment
