# 📚 Curated Learning Resources

## Primary Resources

### 1. Python for Data Analysis, 3rd Edition
**Author**: Wes McKinney (Pandas Creator)

| Chapter | Topic | Best For | Status |
|---------|-------|----------|--------|
| 5 | Getting Started with pandas | Structural foundations | 📖 |
| 6 | Data Loading, Storage, and File Formats | I/O operations | 📖 |
| 7 | Data Cleaning and Preparation | Data quality | 📖 |
| 8 | Data Wrangling | Reshaping & pivoting | 📖 |
| 9 | Plotting and Visualization | EDA & visualization | 📖 |
| 10 | Data Aggregation and Group Operations | Groupby mechanics | 📖 |
| 11 | Time Series | Temporal data handling | 📖 |
| 12 | Advanced pandas | Performance & optimization | 📖 |

**How to Use**:
- Skip chapters 1-4 (Python basics assumed)
- Read sequentially or by topic interest
- Heavy on theory and mechanics
- Study the examples and run them yourself

**Best Resource For**:
- Understanding *why* pandas works the way it does
- Deep dives into alignment, indexing, and reshaping
- Production-level patterns and best practices

### 2. Official Pandas Documentation: "10 Minutes to pandas"
**Source**: https://pandas.pydata.org/docs/user_guide/10min.html

| Section | Focus | Use Case |
|---------|-------|----------|
| Object Creation | Creating Series/DataFrames | Quick reference |
| Viewing Data | Exploring structure | Syntax lookup |
| Selection | Getting/setting values | Most-used reference |
| Missing Data | NaN handling | Problem-solving |
| Operations | Arithmetic & functions | Real-time coding |
| Merge/Join | Combining datasets | Schema queries |
| Grouping | Aggregation patterns | Algorithm exploration |

**How to Use**:
- Keep open in a browser tab while coding
- Use Ctrl+F to quickly find syntax
- Copy-paste examples as starting templates
- Refer to when you know *what* you want but not the *syntax*

**Best Resource For**:
- Quick syntax lookups
- Discovering available methods
- Copy-paste-able code templates
- Last-minute reference during problem-solving

### 3. Kaggle's Micro-Course: Pandas
**Link**: https://www.kaggle.com/learn/pandas
**Duration**: ~4 hours (interactive, browser-based)

| Lesson | Topic | Difficulty |
|--------|-------|-----------|
| 1 | Creating, Reading & Writing | Beginner |
| 2 | Indexing, Selecting & Assigning | Beginner |
| 3 | Summary Functions & Maps | Intermediate |
| 4 | Grouping & Sorting | Intermediate |
| 5 | Data Types & Missing Values | Intermediate |
| 6 | Renaming & Combining | Intermediate |

**How to Use**:
- Work through lessons sequentially
- Follow along in the browser IDE (no local setup needed)
- Complete bite-sized exercises with real datasets
- Use wine reviews and other datasets for practice

**Best Resource For**:
- Hands-on practice with real data
- Building intuition through repetition
- Quick wins to stay motivated
- Practical, less theoretical approach
- Mini-datasets that teach core concepts
